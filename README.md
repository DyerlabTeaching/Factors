## Impetus

The `factor` data type allows us to define categories on our data for grouping observations and measurements into either mutually exclusive groups (e.g., populations, rivers, species) or into groupings that have some kind of underlying ordination meaning they are configured such that the `>` or `<` operator makes sense (e.g., Monday < Tuesday, # of fertilizer, etc.).

## Module Learning Objectives

### Construct and Characterize Factor Data

> Learners will create factor data de novo from raw data and describe the difference between ordered and unordered factors — those where comparison operators like `<` and `>` are meaningful and those where they are not.

- **Bloom's Levels:** Apply (create), Understand (distinguish ordered vs. unordered)
- **Reinforces:** Introduces categorical data as a distinct type from the numeric/character/logical types covered in Basic Data Types.
- **Notes:** The ordered/unordered distinction is the conceptual core — it determines which downstream operations make sense.

### Manipulate Factor Levels for Analysis

> Learners will reorganize, relabel, and otherwise manipulate factor levels using the `forcats` package to prepare categorical variables for grouping and analysis.

- **Bloom's Levels:** Apply
- **Reinforces:** Prepares grouping variables for use in downstream modules such as Analysis of Variance and Graphics, where factors define groups or plotting categories.
- **Notes:** `forcats` is introduced as the tidyverse-consistent tool for this, paralleling the `dplyr`/`stringr` conventions learned elsewhere.
